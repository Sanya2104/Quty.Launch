# \# Quty.Launch 🚀

# 

# \*\*Quty.Launch\*\* — это легковесное, модульное ядро для Android-приложений. Оно предоставляет универсальный WebView-движок для отображения интерфейсов, API-мост для взаимодействия с JavaScript и полный набор инструментов для работы с хранилищем, обновлениями, логами и настройками.

# 

# \---

# 

# \## 📦 \*\*Концепция\*\*

# 

# Quty.Launch — это \*\*ядро\*\*, на основе которого можно строить кастомные приложения для Android. Вместо того чтобы переписывать одну и ту же логику каждый раз, ядро предоставляет готовые решения для:

# 

# \- 🖥️ \*\*Отображения интерфейса\*\* через WebView с поддержкой кастомных оболочек (HTML/CSS/JS, в том числе Web-фреймворков)

# \- 🔌 \*\*Взаимодействия с Android\*\* через JsBridge (API-методы из JavaScript)

# \- 📁 \*\*Управления файлами\*\* через универсальный StorageManager

# \- 🔄 \*\*Обновления приложения\*\* и оболочек

# \- 📊 \*\*Логирования\*\* с ротацией и буферизацией

# \- ⚙️ \*\*Настроек\*\* (ориентация, полноэкранный режим, строгий режим, режим разработчика)

# 

# \---

# 

# \## 🚀 \*\*Ключевые возможности\*\*

# 

# \### \*\*Оболочки оформления (Shells)\*\*

# \- Встроенные оболочки из `assets/shells/`

# \- Кастомные оболочки в формате `.qutyshell` (ZIP-архив с `manifest.json`)

# \- Автоматическая распаковка и загрузка

# \- Поддержка превью, версионирования и обновлений

# 

# \### \*\*API для JavaScript (JsBridge)\*\*

# \- Вызов Android-методов из JavaScript

# \- Асинхронное выполнение с таймаутом

# \- Отправка логов из JavaScript в систему логирования

# 

# \### \*\*Обновление приложения\*\*

# \- Проверка обновлений через сервер

# \- Скачивание APK

# \- Установка через системный установщик

# \- Автоочистка старых файлов

# 

# \### \*\*Настройки\*\*

# \- Ориентация экрана (авто/портрет/ландшафт)

# \- Полноэкранный режим

# \- Строгий режим (панели не появляются даже при свайпе)

# 

# \### \*\*Безопасность\*\*

# \- Все данные хранятся в изолированном хранилище приложения

# \- Не требуется разрешение `MANAGE\_EXTERNAL\_STORAGE`

# \- Использование FileProvider для безопасного шаринга файлов

# 

# \### \*\*Производительность\*\*

# \- Буферизированная запись логов

# \- Кэширование данных

# \- Асинхронные операции с хранилищем
