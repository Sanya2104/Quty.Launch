# Quty.Launch 🚀

**Quty.Launch** — лёгкое и модульное ядро для Android-приложений.

Проект предоставляет универсальный **WebView-движок**, API-мост между JavaScript и Android, а также готовую инфраструктуру для работы с **оболочками, хранилищем, обновлениями, логами и настройками**.

---

## 📦 Концепция

Quty.Launch — это **ядро**, на основе которого можно создавать кастомные Android-приложения без необходимости каждый раз реализовывать одну и ту же системную логику.

Ядро предоставляет готовые решения для:

* 🖥️ **Отображения интерфейса** — WebView с поддержкой кастомных оболочек на HTML/CSS/JavaScript и Web-фреймворках
* 🔌 **Взаимодействия с Android** — JsBridge для вызова Android API из JavaScript
* 📁 **Работы с файлами** — централизованное управление хранилищем через `StorageManager`
* 🔄 **Обновлений** — загрузка и установка обновлений приложения и оболочек
* 📊 **Логирования** — буферизированная запись логов и их ротация
* ⚙️ **Настроек** — управление ориентацией, полноэкранным режимом, строгим режимом и режимом разработчика

---

## 🚀 Возможности

### 🎨 Оболочки (Shells)

Quty.Launch позволяет полностью отделить интерфейс приложения от его системного ядра.

Поддерживаются:

* встроенные оболочки из `assets/shells/`
* пользовательские оболочки в формате `.qutyshell`, `.qsp`, `.qutyshellpack`
* ZIP-архивы с `manifest.json`
* автоматическая распаковка и загрузка оболочек
* версии оболочек
* обновление оболочек
* превью оболочек

Оболочка отвечает за визуальную часть приложения, а Quty.Launch предоставляет ей необходимые API.

---

### 🔌 JavaScript API — JsBridge

`JsBridge` обеспечивает взаимодействие между JavaScript-кодом оболочки и Android.

Возможности:

* вызов Android-методов из JavaScript
* асинхронное выполнение операций
* обработка таймаутов
* передача данных между JavaScript и Android
* отправка логов из JavaScript в системную систему логирования

Пример архитектуры:

```text
┌─────────────────────────────┐
│        Shell / WebView      │
│                             │
│       HTML / CSS / JS       │
└──────────────┬──────────────┘
               │
               │ JsBridge
               ▼
┌─────────────────────────────┐
│        Quty.Launch          │
│                             │
│  Android API / Storage /    │
│ Updates / Logs / Parameters │
└─────────────────────────────┘
```

---

### 🔄 Обновление приложения

Quty.Launch содержит инфраструктуру для обновления самого приложения:

* проверка наличия новой версии через сервер
* скачивание APK
* установка через системный установщик Android
* автоматическая очистка старых файлов

---

### ⚙️ Параметры

Поддерживается управление основными параметрами приложения:

* ориентация экрана:

  * автоматическая
  * портретная
  * ландшафтная
* полноэкранный режим
* строгий полноэкранный режим
* режим разработчика

---

### 📁 Хранилище

Работа с файлами централизована через `StorageManager`.

Предусмотрено разделение данных проекта:

```text
Quty.Launch/
    ├── Logs/
    ├── Shells/
    └── Updates/
```

* `Logs/` — журналы работы приложения
* `Shells/` — пользовательские оболочки
* `Updates/` — загруженные обновления приложения

---

### 📊 Логирование

Система логирования предназначена как для самого ядра, так и для оболочек.

Поддерживаются:

* буферизированная запись
* асинхронная работа
* ротация логов
* сохранение логов в хранилище
* отправка сообщений из JavaScript через JsBridge

---

### 🔐 Безопасность

Quty.Launch использует стандартные механизмы безопасности Android:

* данные хранятся в изолированном хранилище приложения
* не требуется разрешение `MANAGE_EXTERNAL_STORAGE`
* для безопасного предоставления файлов используется `FileProvider`
* доступ оболочек к системным функциям осуществляется через контролируемый API-мост

---

### ⚡ Производительность

Для уменьшения нагрузки на систему используются:

* буферизированная запись логов
* кэширование данных
* асинхронные операции с файлами
* фоновая обработка операций, не требующих немедленного ответа UI

## 📦 Формат Shell

Пользовательская оболочка распространяется в формате `.qutyshell`, `.qsp`, `.qutyshellpack`.

Файл представляет собой ZIP-архив со структурой, определяемой `manifest.json`.

Пример:

```text
MyShell.qutyshell
│
├── manifest.json
├── index.html
├── css/
├── js/
├── assets/
└── preview/
```

`manifest.json` содержит информацию об оболочке, включая её название и версию.

## 🧩 Назначение проекта

Quty.Launch создаётся как универсальная основа для приложений, где необходимо:

* быстро создавать собственные интерфейсы
* использовать HTML/CSS/JavaScript в качестве UI
* получать доступ к функциям Android через API
* подключать сменные оболочки
* централизованно управлять файлами
* реализовывать обновления
* получать диагностические логи

Главная идея проекта — **отделить системное ядро от пользовательского интерфейса**.

```text
                    Quty.Launch
                         │
        ┌────────────────┼────────────────┐
        │                │                │
        ▼                ▼                ▼
      Shell           Android API      Storage
        │                │                │
   HTML/CSS/JS       JsBridge       Logs / Files
        │                │                │
        └────────────────┼────────────────┘
                         │
                         ▼
                    Android App
```
